## 1. PROJECT OVERVIEW

### 1.1 What Sanctuary Is

Sanctuary is a voice-first emotional expression companion. It helps users process their inner world through conversation. It is not a therapy app. It is not a diagnostic tool. It does not assign labels to users.

### 1.2 The North Star Constraint

```
"Sanctuary assists expression. It does not define identity."
```

This constraint applies to every component. Every response. Every internal model. Any code that causes Sanctuary to assign a psychological label, diagnostic category, or fixed identity to a user MUST be rejected. This is not a UX guideline. It is an architectural rule enforced at the policy gate layer.

### 1.3 What This Document Covers

This PRD specifies the complete architectural refactoring of Sanctuary from a prompt-routing system into a stateful, computationally grounded system. The target architecture replaces:

```
User Input → Prompt → LLM Response
```

with:

```
User Input
  → Privacy Distillation
  → Personal World Model (PWM) Update
  → Narrative State Vector Computation (Kalman)
  → Interpretation Engine (Bayesian Hypothesis Competition)
  → Strategy Selection
  → LLM Response Generation (narrow role)
  → Policy Gate
  → Placeholder Restoration
  → TTS Output
  → Persistence
```

The LLM's role is language generation only. All intelligence lives in locally computed layers before the LLM is called.

```python
from dataclasses import dataclass, field
from typing import Dict

@dataclass
class PlaceholderMap:
    # Maps anonymous placeholder → real value
    # e.g. {"PERSON_A": "David", "LOCATION_X": "the office"}
    entity_map: Dict[str, str] = field(default_factory=dict)
    
    # Maps real value → anonymous placeholder (reverse lookup)
    reverse_map: Dict[str, str] = field(default_factory=dict)
    
    # Raw input text
    raw_text: str = ""
    
    # Output after distillation
    distilled_text: str = ""
    
    # spaCy detected entity types per placeholder
    # e.g. {"PERSON_A": "PERSON", "LOCATION_X": "GPE"}
    entity_types: Dict[str, str] = field(default_factory=dict)
```

### 4.4 Narrative State Vector

```python
# backend/core/state/vector.py

from dataclasses import dataclass, field
from typing import Dict, List, Optional
import numpy as np

@dataclass
class RhetoricalStance:
    # How strongly user is asserting their own perspective (0.0-1.0)
    claim_strength: float = 0.5
    
    # How much user is working against their own claim (0.0-1.0)
    self_undermining: float = 0.5

@dataclass
class NarrativeStateVector:
    user_id: str
    session_id: str
    turn_index: int
    
    # DIMENSION 1: Thread Activation
    # Maps thread_id → activation score (0.0-1.0)
    thread_activation: Dict[str, float] = field(default_factory=dict)
    
    # DIMENSION 2: Rhetorical Stance
    rhetorical_stance: RhetoricalStance = field(default_factory=RhetoricalStance)
    
    # DIMENSION 3: Depth Layer (1-5)
    depth_layer: int = 1
    
    # DIMENSION 4: Disclosure Entropy
    # 0.0 = perfectly predicted by prior model
    # 1.0 = maximally novel / surprising
    disclosure_entropy: float = 0.5
    
    # DIMENSION 5: Bifurcation Proximity
    # 0.0 = stable trajectory
    # 1.0 = critical point — qualitative shift imminent
    bifurcation_proximity: float = 0.0
    
    # Kalman filter state — uncertainty covariance matrix
    # Stored as flattened list for JSON serialization
    kalman_uncertainty: List[float] = field(default_factory=list)
    
    def to_numpy(self) -> np.ndarray:
        """Flatten to numpy array for Kalman computation."""
        thread_vec = list(self.thread_activation.values()) if self.thread_activation else [0.0]
        return np.array([
            *thread_vec,
            self.rhetorical_stance.claim_strength,
            self.rhetorical_stance.self_undermining,
            float(self.depth_layer),
            self.disclosure_entropy,
            self.bifurcation_proximity
        ])
```

## 5. COMPONENT SPECIFICATIONS

### 5.1 Privacy Distillation Layer

**File:** `backend/core/privacy/distiller.py`
**Purpose:** Strip all PII from raw user input before any external API call.
**Constraint:** Runs BEFORE any network call. No raw text ever leaves this function unprocessed.

```python
class PrivacyDistiller:
    def __init__(self, nlp_model):
        self.nlp = nlp_model  # spaCy en_core_web_sm, loaded once at startup

    def distill(self, raw_text: str, user_id: str) -> PlaceholderMap:
        """
        Input:  "My boss David criticized me in front of Sarah"
        Output: PlaceholderMap(
```

```python
class NarrativeKalmanFilter:
    def __init__(self, state_dim: int):
        self.Q = np.eye(state_dim) * 0.01   # Process noise
        self.R = np.eye(state_dim) * 0.1    # Observation noise
        self.F = np.eye(state_dim)           # State transition (identity)
        self.H = np.eye(state_dim)           # Observation (all dims observed)

    def update(
        self, prior_state: np.ndarray,
        prior_uncertainty: np.ndarray, observation: np.ndarray
    ) -> tuple[np.ndarray, np.ndarray]:
        """
        Predict:
            x_pred = F @ prior_state
            P_pred = F @ prior_uncertainty @ F.T + Q
        Update:
            K = P_pred @ H.T @ inv(H @ P_pred @ H.T + R)
            x_new = x_pred + K @ (observation - H @ x_pred)
            P_new = (I - K @ H) @ P_pred
        Return: (updated_state, updated_uncertainty)
        """
        pass

    def initialize(self, first_observation: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
        """First turn — no prior. P_0 = I * 1.0 (high initial uncertainty)."""
        return first_observation, np.eye(len(first_observation)) * 1.0
```
